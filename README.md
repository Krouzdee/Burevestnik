# БУРЕВЕСТНИК — Система мониторинга БПЛА

## Описание

**БУРЕВЕСТНИК** — программный комплекс для обнаружения, отслеживания и мониторинга беспилотных летательных аппаратов (БПЛА) в режиме реального времени с использованием модели **YOLO**.

Основные возможности системы:

- 📹 Работа с USB-камерами;
- 🎥 Анализ заранее записанных видеороликов;
- 🤖 Автоматическое обнаружение БПЛА;
- 🎯 Отслеживание объектов с сохранением их идентификаторов (Tracking);
- 📍 Отображение координат обнаруженных объектов;
- 📊 Таблица текущих обнаружений;
- 🚨 Настраиваемая зона интереса (ROI);
- 🔔 Звуковое оповещение при проникновении объекта в охраняемую область;
- 🛤️ Отображение траектории движения объектов.

---

# Установка CUDA (для ускорения работы на NVIDIA)

Если используется видеокарта NVIDIA, рекомендуется установить CUDA, чтобы модель работала значительно быстрее.

## Шаг 1. Проверить наличие видеокарты

В командной строке выполните:

```bash
nvidia-smi
```

Если отображается информация о видеокарте — драйвер установлен.

---

## Шаг 2. Установить драйвер NVIDIA

Скачайте и установите актуальный драйвер с официального сайта:

https://www.nvidia.com/Download/index.aspx

После установки рекомендуется перезагрузить компьютер.

---

## Шаг 3. Установить CUDA Toolkit

Скачать CUDA Toolkit:

https://developer.nvidia.com/cuda-downloads

При установке выберите версию CUDA, совместимую с вашей версией PyTorch.

---

## Шаг 4. Проверить работу CUDA

Откройте Python:

```python
import torch

print(torch.cuda.is_available())
print(torch.cuda.get_device_name(0))
```

Если выводится:

```text
True
NVIDIA GeForce ...
```

значит CUDA настроена корректно.

---

## Установка PyTorch с поддержкой CUDA

Например, для CUDA 12.1:

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

Актуальную команду можно получить на официальном сайте:

https://pytorch.org/get-started/locally/

# Использование

## Выбор источника видео

Доступны два режима работы:

- Камера
- Видеофайл

При выборе камеры необходимо указать устройство из списка.

При выборе видеофайла нажмите кнопку **«Обзор»** и выберите файл.

---

## Зона интереса (ROI)

Кнопка **«Включить зону интереса»** позволяет нарисовать охраняемую область поверх видео.

При попадании обнаруженного БПЛА в эту область:

- рамка зоны станет красной;
- статус изменится на **«ТРЕВОГА»**;
- прозвучит звуковой сигнал.

---

## Таблица обнаружений

В таблице отображаются:

- ID объекта;
- Тип объекта;
- Координаты X;
- Координаты Y;
- Статус.

---

## Отображение траектории

Переключатель **«Отображать трекеры»** включает или отключает отображение траектории движения обнаруженных объектов.

# Использование GPU

При запуске приложение автоматически определяет доступность CUDA:

```python
if torch.cuda.is_available():
    DEVICE = "cuda"
else:
    DEVICE = "cpu"
```

При наличии поддерживаемой видеокарты вычисления выполняются на GPU, что значительно увеличивает скорость обработки видео.

---

# Возможные проблемы

### CUDA не используется

Проверьте:

```python
import torch
print(torch.cuda.is_available())
```

Если выводится `False`:

- установите драйвер NVIDIA;
- установите CUDA Toolkit;
- установите версию PyTorch с поддержкой CUDA.

---

### Камера не отображается

Проверьте:

- подключена ли камера;
- не используется ли она другим приложением;
- имеются ли разрешения Windows на использование камеры.

---

### Не загружается модель

Убедитесь, что рядом с `main.py` находятся файлы:

drone_detection.pt

best_drone_detect_scale.pt
